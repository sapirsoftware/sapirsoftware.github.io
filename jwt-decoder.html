Check the signature (HS256 only)

If the token uses HS256 and you have the shared secret, this checks it here in the browser. RS256 and ES256 need the issuer's public key and are not checked here.

Things worth knowing

  • A JWT is not encrypted. Header and payload are base64url text. Anyone with the token can read them, so nothing private belongs in a payload.
  • A token is a credential. Treat one like a password: don't paste production tokens into sites that send them to a server, don't put them in bug reports, and rotate anything you have shared.
  • alg: none means the token is unsigned. A server that accepts it accepts forgeries.
  • Expiry is not revocation. Until exp passes, a stolen token still works unless the issuer keeps a deny list.
