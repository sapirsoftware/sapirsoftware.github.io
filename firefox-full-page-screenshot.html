How to take a full page screenshot in Firefox

Firefox can capture a whole scrolling page without installing anything. Here are the three built-in ways, what each is good for, and what to do when the page is too long or contains things you shouldn't share.

On this page
  1. 1. The screenshot tool
  2. 2. The :screenshot command
  3. 3. Print to PDF
  4. When the built-in tools fall short

1. The screenshot tool

  1. Right-click an empty part of the page and choose Take Screenshot — or press Ctrl+Shift+S (Mac: Cmd+Shift+S).
  2. Click Save full page in the top-right corner.
  3. Choose Download or Copy.

It saves a PNG. Good for most ordinary pages.

2. The :screenshot command

Open the Web Console (Ctrl+Shift+K, Mac Cmd+Option+K) and type:

:screenshot --fullpage

Useful options: --clipboard copies instead of downloading, --delay 3 waits three seconds (for hover menus), and --dpr 2 captures at double resolution.

3. Print to PDF

Press Ctrl+P, set the destination to Save to PDF, and save. You get every part of the page as a multi-page PDF, but in the page's print layout — menus, backgrounds and some images may be hidden or rearranged. More on this: how to save a web page as a PDF.

When the built-in tools fall short

  • Very long pages can exceed the maximum image size and come out cut off.
  • Lazy-loaded images may be blank if you haven't scrolled past them first.
  • Scrolling panels — web apps like webmail and dashboards scroll an inner panel, not the page, so a full-page capture only gets the frame around it.
  • Private details — an email address, an order number, a key in a settings page — end up in the image, and blacking them out afterwards leaves the original file on disk. See how to redact a screenshot safely.
