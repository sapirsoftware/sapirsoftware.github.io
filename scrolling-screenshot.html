How to take a scrolling screenshot

A normal screenshot stops at the edge of your screen. A scrolling screenshot — also called a long or full-page screenshot — captures everything, top to bottom. Here's the built-in way on each device, and what to do when the result comes out broken.

Web pages on any computer: use the browser

If what you want to capture is a web page, the operating system's screenshot tool is the wrong place to start. Every major browser can capture the whole page itself:

BrowserHowSaves as
ChromeF12, then Ctrl+Shift+P (Mac Cmd+Shift+P), type full size, choose Capture full size screenshotPNG
EdgeCtrl+Shift+S, then Capture full pagePNG
FirefoxRight-click the page, Take Screenshot, Save full pagePNG
SafariFile → Export as PDFOne long PDF

Windows

Win+Shift+S and PrtScn capture what is on screen, not a scrolling window. For web pages use the browser methods above. For scrolling inside other apps — a long chat, a document viewer — the free, open-source ShareX has a Scrolling capture mode that scrolls the window and stitches the result.

Mac

The macOS screenshot toolbar (Cmd+Shift+5) has no scrolling mode. For web pages, use Firefox's Save full page, Chrome's DevTools command, or Safari's Export as PDF, which gives you the whole page as a single tall PDF page — handy for reading, awkward for printing.

iPhone and iPad

  1. In Safari, take a screenshot as usual (side button + volume up).
  2. Tap the thumbnail that appears in the corner.
  3. Choose Full Page at the top, then Done → Save PDF to Files.

It works in Safari and some other apps, and always saves a PDF rather than an image.

Android

On Android 12 and later, take a screenshot and tap Capture more, then drag the bottom handle to choose how much to include. Samsung phones call it Scroll capture and repeat the tap to keep scrolling.

When the result comes out broken

Long captures of web pages fail in the same four ways, whichever tool you use:

  • The header repeats down the image — the page has a sticky header, and each scrolled section captured it again.
  • Images are blank — they load only when scrolled into view, and the capture didn't wait for them.
  • Only the frame is captured — web apps like Gmail, Notion or dashboards scroll an inner panel, not the page, so page-level tools see nothing to scroll.
  • The image is blurry or cut off — very long pages hit the browser's maximum image size, and some tools quietly shrink them.
