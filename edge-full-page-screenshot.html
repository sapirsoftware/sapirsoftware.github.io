Full page screenshots in Microsoft Edge

Edge can capture a whole scrolling page by itself, with no extension: it's called Web capture. Here's how to use it, where it falls short, and what to use when it does.

On this page
  1. Web capture: the built-in way
  2. When the capture comes out wrong
  3. Using a screenshot extension in Edge
  4. Saving the page as a PDF instead

Web capture: the built-in way

  1. Open the page and press Ctrl+Shift+S (on a Mac, Cmd+Shift+S). Or open the … menu and choose Screenshot.
  2. Choose Capture full page. (Capture area is for part of the screen.)
  3. The image opens in a small editor where you can draw on it. Click the save icon to download it, or copy it.

If the shortcut does nothing, use the … menu instead: some Edge versions have changed the shortcut, your organisation may have turned Web capture off, or another app may have claimed the keys.

When the capture comes out wrong

ProblemWhyFix
Blank or grey images lower downThey load only when scrolled into viewScroll to the bottom and back up, then capture
Only one screenful of an email or chatThe content scrolls inside a panel, not the pageUse a tool that can capture a scrolling panel (below)
Header or cookie banner covering contentSticky elements are part of the layoutClose banners first
The page is cut off at the bottomVery long pages exceed the capture limitSave as PDF, or capture in parts

Using a screenshot extension in Edge

Edge runs extensions from the Chrome Web Store. Open an extension's Chrome Web Store page in Edge, click Allow extensions from other stores in the banner at the top, confirm, then click Add to Chrome. It installs in Edge.

Full Page Screenshot (works in Chrome and Edge, free)

Scrolls the page slowly so images load, shows sticky headers once, and can capture a panel that scrolls on its own, like a Gmail message list. Saves PNG, JPEG or PDF, and can black out emails, phone and card numbers before the image is made. No account, nothing uploaded.

Saving the page as a PDF instead

For text you want to keep or search later, a PDF is often better than a picture: Ctrl+P, set Printer to Save as PDF, and save. The layout can differ from the screen because sites style pages for printing. More on saving pages as PDF.
