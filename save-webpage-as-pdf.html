How to save a webpage as a PDF

Chrome can save any page as a PDF with no extra software. Often that's all you need. When the PDF comes out looking different from the page on screen, the second method keeps it the way you see it.

1. Chrome's Print to PDF (free, built in)

  1. Open the page and press Ctrl+P (Mac: Cmd+P).
  2. Set Destination to Save as PDF.
  3. Open More settings and tick Background graphics, or coloured sections and many images disappear.
  4. Click Save.

The text stays selectable and links usually stay clickable. The catch: the page is re-laid out for printing, using the site's print styles. Sidebars vanish or move, dark themes turn white, images that hadn't loaded yet are missing, and sticky headers can repeat on every sheet.

Tip: scroll to the bottom of the page before printing, so images that load on scroll are there.

2. Keep it exactly as it looks on screen

If you need the PDF to match what you see (a design review, a dashboard, a receipt that prints badly), capture the page as it's displayed and save that as a PDF.

Firefox, Safari and Edge

Firefox has this built in and it is genuinely good: right-click an empty part of the page, choose Take Screenshot, then Save full page. That gives a PNG of the whole page; to get a PDF instead, print to PDF as above. Firefox also keeps its own reader-style printing, so a long article usually comes out clean without any extension.

Edge is Chrome underneath, so every Chrome instruction on this page applies, including the DevTools command. Safari can export a whole page: File → Export as PDF, which captures the full length rather than one screen.

Our extension is Chrome and Edge only. If you are on Firefox, the built-in screenshot tool above is the answer, and we would rather say so than pretend otherwise.

Converting a page to PDF without installing anything

"Convert webpage to PDF" and "print to PDF" are the same job in Chrome: the Print dialog does the converting, and no upload or online converter is needed. Avoid pasting a private URL into an online converter; the page is fetched by their server, and anything behind a login won't come out right anyway.

For a page you're signed in to, always convert from your own browser, which already has the session.

Common problems

The PDF is cut off at the right edge

In the print dialog, set Scale to Fit to page width, or switch Layout to Landscape.

Only the first page came out

Some web apps put their content in an inner scrolling box, which printing doesn't expand. Capture the scrolling panel instead.
