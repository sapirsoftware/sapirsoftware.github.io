Why it looks so strange

Almost every browser's user agent starts with Mozilla/5.0, and Chrome's also mentions AppleWebKit, KHTML and Safari. That's history, not confusion: for decades browsers copied each other's strings so that servers checking for a rival wouldn't send them a stripped-down page. The result is a string that names four browsers and means one.

Modern Chrome also freezes parts of the string (a "reduced" user agent) and sends the real detail in separate Sec-CH-UA client-hint headers instead. That's why the version numbers above may look rounder than you expect.

Changing your user agent

Two ways, and they do different things:

  • Chrome DevTools (free, built in): F12 → ⋮ → More tools → Network conditions → untick "Use browser default". Changes what servers receive and what page JavaScript sees, for that tab while DevTools is open.
  • A header rule: changes the User-Agent header sent to chosen sites, permanently, without DevTools open. Page JavaScript still sees your real browser.
