Automatic matches are a starting point. Scroll through every page before you save: scanned pages have no text to search, and text split oddly in the file can be missed.

Why a box drawn in a PDF editor isn't a redaction

Most PDF editors, and every "add a rectangle" tool, put the black box on a layer above the page. The text is still underneath. Anyone can select it and copy it, search for it, or just delete the box. Court filings and government reports have leaked this way more than once.

Real redaction removes the content. Paid tools like Adobe Acrobat Pro do it by editing the text inside the file. This page does it the blunt, reliable way: it draws each page as an image, burns the boxes in, and writes a new PDF from those images. Nothing from the original file is copied across: no text, no hidden layers, no form data, no attachments, no metadata.

The better version: never create the exposure

If the PDF comes from a web page, such as an invoice, a support ticket or a dashboard, the safer order is to black the details out before the PDF exists.
