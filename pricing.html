Pricing

Both extensions are useful free, for good. Pro removes the monthly limits and adds a few tools for people who use them every week. Pay monthly, yearly, or once.

Full Page Screenshot

Capture a whole web page, and black out private details before the picture exists.

Free

  • Whole page, part of a page, or a scrolling panel
  • PNG, JPEG and PDF, copy to clipboard, capture delay, your own file names
  • 3 captures a month with private info blacked out, including finding it automatically
  • 10 PDFs a month with smart page breaks and clickable links

Pro

  • Unlimited blacked-out captures and automatic finding of emails, card numbers, phone numbers and keys
  • Unlimited smart PDFs
  • Capture a whole list of pages in one run

HeaderForge

Modify HTTP request and response headers, unblock CORS, block or redirect requests, and see which rule fired.

Free

  • Unlimited request and response header rules, regex patterns, profiles
  • One-click CORS for a site, ready-made presets, block and redirect rules
  • ModHeader and JSON import, pause, this-tab-only, optional sync
  • 5 URL tests a month

Pro

  • How often each rule ran on this tab
  • A live list of this tab's requests and which rule touched each
  • Unlimited URL tests and a history of them
  • Variables like {{token}} in your rules
