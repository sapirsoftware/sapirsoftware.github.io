How to save a web page as an image

You want the whole page — not just the part on your screen — as a single picture you can attach, archive or annotate. Every desktop browser can do it without installing anything. Here's how, which format to choose, and how to fix the usual problems.

On this page
  1. The built-in way in each browser
  2. PNG, JPG or PDF?
  3. Blurry, cut off, or blank images
  4. Before you share it

The built-in way in each browser

Chrome

  1. Press F12 to open DevTools.
  2. Press Ctrl+Shift+P (Mac: Cmd+Shift+P).
  3. Type full size and choose Capture full size screenshot. A PNG downloads.

Edge

Press Ctrl+Shift+S, choose Capture full page, then the save icon.

Firefox

Right-click an empty part of the page, choose Take Screenshot, then Save full page and Download.

Safari

Safari has no full-page image command. File → Export as PDF saves the whole page as one tall PDF, which you can open in Preview and export as PNG or JPEG.

PNG, JPG or PDF?

FormatBest forWatch out for
PNGText, code, dashboards, bug reports — sharp and losslessLarge files for long pages
JPGPhoto-heavy pages, email attachmentsText edges get fuzzy
PDFVery long pages, printing, links that stay clickableNot an image — some apps won't accept it

Blurry, cut off, or blank images

  • Cut off or blurry at the bottom — browsers cap how big one image can be, so very long pages get truncated or scaled down. Save as PDF instead, or capture in parts.
  • Blank rectangles where pictures should be — the page loads images only as you scroll. Scroll to the bottom and back up before capturing, then try again.
  • The header repeats down the page — a sticky header was captured in every section. Some tools hide it after the first; DevTools usually doesn't have the problem because it renders the page in one go.
  • Only a small box got captured — the content scrolls inside a panel (email, chat, dashboards), not the page. You need a tool that can capture that panel.

Before you share it

A full-page image often contains more than you meant to send: an email address in the header, an order number, an API key in a settings panel. Cropping or drawing over it afterwards leaves the original file on disk. See how to redact a screenshot safely.
